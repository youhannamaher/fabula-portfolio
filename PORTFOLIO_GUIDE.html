⚡ How Changes Are Published

Recommended

Option 1: 100% In Your Browser

No code, no command line, and no terminal. You can edit files directly on GitHub from any computer.

  1. Click the direct GitHub link for the file you want to change.
  2. Click the Pencil icon (Edit).
  3. Paste the updated text provided by Claude or ChatGPT.
  4. Click the green "Commit changes" button.
  5. Done! GitHub Actions builds and publishes your live site in 90 seconds.
Local PC

Option 2: On Your Windows Computer

If you have the portfolio folder open on your computer, use the 1-click batch files:

  1. open-portfolio-preview.cmd: Opens a live preview in your browser & on phone.
  2. update-videos-preview.cmd: Refreshes video gallery index when you add videos.
  3. push-to-github.cmd: Double-click to send all changes to GitHub and publish automatically!

🤖 Master Prompt for Claude / ChatGPT

Copy and paste this prompt whenever starting a new conversation with Claude, ChatGPT, or Gemini. It teaches the AI everything about your website: 

You are my personal technical assistant helping me maintain and update my professional portfolio website (Fabula Ayman - Content Creator, Scriptwriter & Creative).

The site is built with React 19, TypeScript, Tailwind CSS, and Vite, and is automatically deployed on GitHub Pages: https://youhannamaher.github.io/fabula-portfolio/

Repository Architecture:
1. "src/data/profile.ts":
   - Personal info: name, title, email, location, languages, linkedin, cvPath, profileImage, about
   - skills: list of { title, description }
   - experience: list of { role, company, period, description }
   - projects: list of { title, category, role, objective, tools, link, logo }

2. "public/videos/metadata.json":
   - filename: exact video filename in public/videos/
   - title: video title displayed on the site
   - category: e.g. "Branding", "Documentary", "Travel"
   - project: e.g. "Williams Art", "Documentary & Travel" (the filter tabs and project sections on the website are generated AUTOMATICALLY from this field!)
   - views: optional, e.g. "15K+ views" or "197K+ views" (omit or leave "" to hide the views badge)
   - order: display order number (1, 2, 3...)

Deployment & Workflow:
- Any commit to the "main" branch triggers GitHub Actions to run the build (which automatically re-indexes metadata.json into videos.json) and updates the live site in 1-2 minutes.
- On Windows locally, "push-to-github.cmd" commits and pushes changes.
- Note: GitHub's browser file upload supports files up to 25 MB; for larger video files, add them locally and double-click "push-to-github.cmd".

Rules for your responses:
- Always provide the EXACT code snippet ready to be copy-pasted.
- Specify the exact file path and GitHub edit link so I can paste it immediately.
- Explain the steps simply without complex developer jargon.

💡 Step-by-Step Task Guides

👁️ Task 1: Update Video View Counts ▼
  1. Open the GitHub edit page: Edit metadata.json.
  2. Copy the contents of the file and send it to Claude with this prompt:
"Here is my metadata.json. I want to change the view count of 'William's Passion' to '50K views' and 'Graeco-Roman Museum' to '25K views'. Please give me the updated file content."

3. Copy the updated JSON from Claude, paste it into the GitHub editor, and click "Commit changes".

🔗 Task 2: Add or Update Your Freelance Project Link ▼
  1. Open the GitHub edit page: Edit profile.ts.
  2. Look for line 85 under Freelance Scriptwriting Project.
  3. Replace link: "https://instagram.com" with your actual URL (e.g. link: "https://vimeo.com/your-project").
  4. Click "Commit changes" at the bottom.
🎥 Task 3: Add a New Video to the Portfolio ▼
  1. Upload your new video (.mp4 or .mov) to public/videos/ and click "Commit changes".
  2. Open metadata.json.
  3. Ask Claude:
"I uploaded a video named 'Summer_Commercial.mov'. Here is my metadata.json. Please add an entry for it with Title: 'Summer Commercial', Project: 'Williams Art', Category: 'Branding', Views: '20K views'."

4. Paste the updated JSON and click "Commit changes".

💼 Task 4: Add a New Work Experience or Client ▼
  1. Open profile.ts.
  2. Ask Claude:
"Here is my profile.ts. I completed a freelance project: Role: Creative Scriptwriter, Company: Brand Name, Period: 2024, Description: [Paste short description]. Please add it to the experience array."

3. Paste the code into GitHub and click "Commit changes".

💡 Pro Tip: After clicking "Commit changes" on GitHub, visit the GitHub Actions page. When the yellow running circle turns into a green checkmark, your live site has been updated!
